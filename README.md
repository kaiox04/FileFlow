# FileFlow

FileFlow é um organizador automático de arquivos desenvolvido em Python.

O programa identifica extensões de arquivos e os organiza automaticamente em pastas como:

- Imagens
- Documentos
- Músicas
- Vídeos
- Textos
- Programas
- Aplicativos

## Funcionalidades

- Seleção de pasta para organização
- Organização automática por extensão
- Criação automática das pastas
- Contagem de arquivos organizados
- Identificação de arquivos sem categoria
- Interface gráfica
- Executável para Windows

## Tecnologias utilizadas

- Python
- Tkinter
- os
- shutil
- PyInstaller

## Como usar

1. Abra o FileFlow.
2. Selecione a pasta que deseja organizar.
3. Clique em "Organizar Arquivos".
4. Confirme a operação.
5. O FileFlow organiza os arquivos automaticamente.
